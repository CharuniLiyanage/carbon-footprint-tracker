# 🌱 CarbonTrack Lite

CarbonTrack Lite is a smart web application that helps users track their daily carbon footprint and adopt eco-friendly habits through data visualization and intelligent suggestions.

---

## 🚀 Features

- 🔐 User Authentication (Firebase)
- 📋 Daily Activity Logging (Transport & Food)
- 📊 Carbon Footprint Calculation
- 📈 Interactive Dashboard with Charts
- 🤖 Smart Suggestions (AI-like logic)
- 🎯 Goal Tracking (optional)
- 🌍 Clean and responsive UI

---

## 🧠 How It Works

Users log their daily activities such as:
- Transport (Car, Bus, Bike, Walking)
- Food (Vegetarian / Non-Vegetarian)

The system calculates carbon emissions based on predefined values and displays:
- Total carbon footprint
- Weekly trends
- Personalized suggestions to reduce impact

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Firebase (Auth, Firestore, Hosting)
- **Charts:** Chart.js
- **Styling:** CSS / Tailwind
